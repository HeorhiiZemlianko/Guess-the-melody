# 🎵 Music Battle — Угадай мелодию

Интерактивная музыкальная викторина, в которой игроки угадывают песни по коротким отрывкам из YouTube. Проект поддерживает несколько режимов игры, систему подсказок, уровни сложности и локальный рекорд.

🔗 **[Играть онлайн](https://guessthemelody.vercel.app/)**

## ✨ Основные возможности

- **5 режимов игры:**
  - `Классический` — стандартные раунды на время.
  - `Блиц` — общий таймер на 60 секунд (+5 сек за верный ответ, -3 сек за ошибку).
  - `Выживание` — 3 жизни, игра до первой ошибки.
  - `Дуэль` — игра на одном устройстве по очереди (2 игрока).
  - `Тематический` — выбор жанра (Рок, Поп, Ретро).
- **4 уровня сложности:** от Лёгкого (4 варианта) до Хардкора (ручной ввод).
- **Система подсказок:** убрать 2 варианта, показать исполнителя, добавить время, пропустить трек.
- **Система очков и серий:** множитель за серию правильных ответов.
- **Сохранение рекорда:** лучший результат сохраняется в `localStorage`.

## 🛠 Технологии

- **Frontend:** Vanilla JavaScript (ES6 Modules), HTML5, CSS3 (Flexbox/Grid).
- **API:** YouTube Data API v3, iTunes Search API.
- **Backend:** Vercel Serverless Functions (Node.js).
- **Стили:** Разбиты на модули (`src/css/`), используется методология БЭМ-подобного нейминга.
- **Архитектура JS:** Разделение на слои (`config`, `state`, `core`, `ui`, `game`, `api`, `utils`).
